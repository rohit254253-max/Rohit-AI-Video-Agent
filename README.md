# Rohit AI Video Agent

An open-source AI video generation agent.

## Goal

Create high-quality videos using open-source AI models without relying on paid Kling or Runway APIs.

## Planned Architecture

User Prompt
↓
AI Video Agent
↓
Story Planner
↓
Scene Planner
↓
Prompt Engineer
↓
Image / Video Generation
↓
Quality Checker
↓
FFmpeg Video Editor
↓
Final Video

## Technology

- Python
- ComfyUI
- Open-source video models
- FFmpeg
- FastAPI
- Web UI
